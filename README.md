# AI 학습 도우미 (AI Tutor) - 실행 가이드

이 프로젝트는 React + Vite 기반의 프론트엔드 애플리케이션입니다.
Visual Studio Code (VS Code)에서 오류 없이 바로 실행하려면 아래 단계를 따라주세요.

## 🚀 VS Code에서 바로 실행하는 방법

### 1. 필수 프로그램 설치
먼저 **Node.js**가 설치되어 있어야 합니다. (없다면 [nodejs.org](https://nodejs.org/)에서 설치하세요)

### 2. 프로젝트 열기 및 설정
VS Code에서 이 폴더를 열고 터미널(Ctrl+`)을 엽니다.

### 3. 패키지 설치
아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
```bash
npm install
```

### 4. 웹사이트 실행 (중요!)
백엔드 설정 없이 프론트엔드만 바로 실행하려면 **반드시 아래 명령어를 사용하세요.**
```bash
npm run dev:client
```
> 주의: `npm run dev`를 실행하면 서버 연결 오류가 발생할 수 있습니다. 꼭 `dev:client`를 사용해 주세요.

### 5. 웹사이트 접속
터미널에 `Local: http://localhost:5000/` 주소가 나타나면,
**Ctrl (또는 Cmd) 키를 누른 채 클릭**하거나 브라우저 주소창에 입력하여 접속하세요.

---

## 📂 프로젝트 구조
- `client/src`: 모든 React 소스 코드가 들어있습니다.
- `client/src/pages`: 주요 페이지 (채팅, 대시보드 등)
- `client/src/components`: UI 컴포넌트

## ✨ 주요 기능
- **채팅 모드**: AI 튜터와 대화 (모의 응답)
- **비교 모드**: GPT, Gemini, Claude 동시 비교
- **추천 시스템**: 문제 유형별 최적 모델 추천
- **학습 경로**: 과제별 단계별 가이드 제공

문제가 발생하면 터미널 로그를 확인해 주세요.
